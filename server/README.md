# 🚀 Vertex AI - Free Cloud Database Server

خادم قاعدة بيانات خفيف جداً، صفر متطلبات خارجية (Zero-Dependencies)، يعتمد على محرك Node.js القياسي فقط بدون أي مكتبات خارجية ثقيلة.

---

## ⚡ 1. التشغيل المحلي (Local Run)

بضغطة واحدة:
- اضغط مرتين على ملف `start-server.bat` في المجلد الرئيسي للمشروع.
- أو عبر التيرمنال:
  ```bash
  npm run server
  ```
- سيعمل الخادم تلقائياً على المنفذ: `http://localhost:5000`
- يقوم الخادم بحفظ كل السجلات والفعاليات وعدد الزيارات في ملف محلي:
  `server/data/vertex-db.json`

---

## 🌐 2. الرفع على سيرفر مجاني 100% مدى الحياة (Free Cloud Hosting)

يمكنك رفع مجلد السيرفر مجاناً وبدون أي تكلفة أو فيزا على منصات الاستضافة السحابية المجانية:

### الخيار الأفضل والأسهل: **Render.com** (مجاني 100%)
1. أنشئ حساباً مجانياً على [Render.com](https://render.com).
2. اضغط **New +** ثم اختر **Web Service**.
3. اربط مستودع GitHub الخاص بمشروعك (أو ارفع كود `server`).
4. في الإعدادات:
   - **Root Directory**: `server`
   - **Build Command**: فارغ أو اتركه كما هو
   - **Start Command**: `node index.js`
   - **Instance Type**: `Free`
5. اضغط **Deploy Web Service**.
6. ستحصل على رابط مجاني مثل: `https://vertex-db-server.onrender.com`.

### 🔗 ربط الرابط السحابي بالموقع:
1. افتح الموقع واذهب إلى **لوحة تحكم الأدمن** (`/admin`).
2. ستجد بطاقة **"قاعدة البيانات السحابية (Cloud DB)"**.
3. اضغط على **"إعدادات الرابط السحابي"** وضع رابط Render الخاص بك (مثلاً `https://vertex-db-server.onrender.com`).
4. اضغط **"حفظ واختبار الاتصال"**.
5. مبروك! سيقوم الموقع الآن بحفظ وتحديث كافة البيانات في السحابة ومزامنتها تلقائياً بين جميع الأجهزة والهواتف مجاناً 24/7!

---

## 📡 واجهات الـ API المتاحة (REST Endpoints)

- `GET /api/status`: حالة السيرفر وعدد السجلات والفعاليات المخزنة.
- `GET /api/records`: جلب كافة سجلات طلبات الخدمات المسجلة.
- `POST /api/records`: حفظ وتحديث سجلات الخدمات.
- `GET /api/events`: جلب جدول الفعاليات وورش العمل.
- `POST /api/events`: تحديث وإضافة الفعاليات مع الحفظ الفوري.
- `GET /api/visits`: جلب عدد الزيارات الكلي للموقع.
- `POST /api/visits`: زيادة وتحديث عداد الزيارات.
